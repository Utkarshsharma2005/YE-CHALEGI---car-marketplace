# Lumina Drive

You are an award-winning Creative Director, Senior Product Designer, and Senior React Frontend Engineer.

Design and build a luxury automotive marketplace frontend that feels worthy of Awwwards.

Do NOT copy Cars24 or CarDekho.

Instead, take inspiration from Apple, Porsche, Lamborghini, Rivian, Tesla, Linear, Stripe, and Arc Browser.

The experience should feel cinematic.

• Every page transition should be fluid.

• Micro interactions everywhere.

• Responsive on every screen.

• Mobile first.

• Glass morphism only where appropriate.

• Premium typography.

• Elegant spacing.

• Lots of whitespace.

• Smooth hover states.

• Custom cursor.
